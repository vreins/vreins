# 06 배포

> 상태: 작성완료
> 준수 강도: 권장 — 목차 구조는 필수, 표현은 자유
> 최종갱신: 2026-09-21

`06-deployment-{SR번호}.md` 를 이 목차대로 쓴다.

파일 이름은 `06-deployment-{SR번호}.md` 다. 제목은 폴더명이 갖는다 —
`20260714_SR2607-01292_규격별중량구간기준변경` 이면 `06-deployment-SR2607-01292.md` 다.
**번호를 앞에 두는 이유** — 폴더 안에서 단계 순으로 서고, 「설계 문서만」 같은 걸 고를 수 있다.
**SR번호를 붙이는 이유** — 같은 이름이 수백 개가 되면 탭·검색·그래프에서 구분이 안 된다.
제목은 25자가 넘고 한 폴더 안에서 예닐곱 번 반복된다. SR번호는 짧고 유니크하다.

머리말은 이렇게 연다. **빼면 목차가 이 문서를 집지 못한다.**

```yaml
---
type: srs
id: SR2607-01292
system: MESD
techbase: [Acme_ERP_MES_V6] # 위키 {유형}/COMMON/techbase/ 폴더명 그대로
화면코드: [MESD610Q06]               # 고친 화면. 「이 화면 앞서 누가 고쳤나」를 기계가 센다
화면대역: "610"                      # 화면코드 5~7자리
description: 한 줄 요약               # 목차가 이걸 긁어 간다. 없으면 목차에서 고를 수 없다
updated: 2026-07-14
---
```

| 대상 | 서버경로 | 버전 |
|---|---|---|

**서버경로로 적는다.** 로컬 경로는 사람마다 다르다.

## 2. 절차

    순서대로. 되돌릴 수 없는 지점을 표시한다.

| 시각 | 무엇 | 결과 |
|---|---|---|

## 4. 롤백

무엇을 어떻게 되돌리는가. **배포 전에 적는다** — 사고 난 뒤엔 못 쓴다.

## 5. 미검증 배포 사유

테스트를 건너뛰고 배포했으면 여기 적는다.
긴급 배포는 허용되지만 **사유 없는 배포는 허용되지 않는다.**
