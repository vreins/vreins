# 05 테스트

> 상태: 작성완료
> 준수 강도: 권장 — 목차 구조는 필수, 표현은 자유
> 최종갱신: 2026-09-21

`05-testing-{제목}.md` 를 이 목차대로 쓴다.

파일 이름은 `05-testing-{제목}.md` 다. `{제목}` 은 작업 폴더 이름에서 날짜·SR번호를
뗀 나머지고, 밑줄은 하이픈으로 바꾼다 — `20260114_SR2601-00001_조회조건추가` 면
`05-testing-조회조건추가.md` 가 된다.
**번호를 앞에 두는 이유** — 폴더 안에서 단계 순으로 서고, 「설계 문서만」 같은 걸 고를 수 있다.
**제목을 붙이는 이유** — 같은 이름이 수백 개가 되면 탭·검색·그래프에서 구분이 안 된다.

머리말은 이렇게 연다. **빼면 목차가 이 문서를 집지 못한다.**

```yaml
---
type: srs
id: SR2601-00001
system: ABCD
techbase: [Acme_ERP_MES_V6] # techbase/ 폴더명 그대로
화면코드: [ABCD610Q06]               # 고친 화면. 「이 화면 앞서 누가 고쳤나」를 기계가 센다
화면대역: "610"                      # 화면코드 5~7자리
description: 한 줄 요약               # 목차가 이걸 긁어 간다. 없으면 목차에서 고를 수 없다
updated: 2026-01-14
---
```
