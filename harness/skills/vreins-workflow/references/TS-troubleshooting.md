## 1. 요약

## 2. 현상

발생일시 · 인지경로 · 증상 · 영향범위 · 심각도.
심각도는 긴급 / 높음 / 중간 / 낮음.

## 3. 타임라인

|---|---|

인지 → 조사 → 조치 → 복구 → 확인.

## 4. 조사 과정

확인한 것과 **배제한 것**. 로그 · 쿼리 결과 · 재현 시도.

배제한 원인을 남기는 이유 — 다음에 유사 증상이 나왔을 때
이미 배제된 것을 다시 파지 않아 시간을 크게 아낀다.
