# 끝났다고 말하기 전에

> 상태: 작성완료
> 준수 강도: 필수
> 최종갱신: 2026-09-21
> 출처: obra/superpowers 의 `verification-before-completion` 파생 (MIT · Jesse Vincent)
>       → `harness\LICENSE` · `harness\ATTRIBUTION.md`

## 한 줄

**확인 없이 끝났다고 말하는 것은 효율이 아니라 거짓말이다.**

근거가 먼저고 주장이 나중이다.

## 철칙

```
새로 확인한 근거 없이 완료를 말하지 않는다
```

**지금 이 답변에서** 확인 명령을 돌리지 않았으면 통과한다고 말할 수 없다.
직전 답변에서 돌린 것도 「새로」가 아니다 — 그 사이에 코드가 바뀌었다.

## 게이트

```
1  무슨 명령이 이 주장을 증명하나      정한다
2  그 명령을 통째로 돌린다            일부만 돌리지 않는다
3  출력을 끝까지 읽는다               종료코드 · 실패 건수
4  출력이 주장을 뒷받침하나
5  그제서야 말한다

한 단계라도 건너뛰면 검증이 아니라 거짓말이다
```

## 주장과 근거

| 주장 | 필요한 것 | 부족한 것 |
|---|---|---|
| 빌드가 통과한다 | `dotnet build` 종료코드 0 | 「린터가 통과했다」 — 린터는 컴파일을 안 한다 |
| 버그를 고쳤다 | **원래 증상**을 재현해 보고 사라짐 | 코드를 고쳤으니 됐겠지 |
| 쿼리가 맞다 | 실제 데이터로 건수·값 대조 | 문법이 맞다 |
| 화면이 뜬다 | 띄워서 눈으로 봄 | 빌드가 됐다 |
| **배포됐다** | **서비스를 멈췄다 올리고 로그 확인** | 파일을 덮었다 |
| 요구를 다 만족했다 | 요구사항 한 줄씩 대조표 | 빌드가 통과했다 |

**Level2 TASK 는 상주 프로세스다.** 파일만 덮으면 안 바뀐다 — 서비스를
멈췄다 올려야 한다. 「배포했다」를 말하려면 재기동 후 로그를 봐야 한다.

## 멈춰야 하는 신호

- 「아마」 · 「~일 것이다」 · 「~인 듯하다」를 쓰고 있다
- 확인 전에 만족을 표현하고 있다 — 「좋습니다」 · 「완료」 · 「잘 됐네요」
- 확인 없이 커밋·체크인으로 가려 한다
- 도구나 에이전트의 성공 보고를 그대로 믿고 있다
- 일부만 확인하고 전체를 미루어 짐작하고 있다
- 「이번 한 번만」이라는 생각이 든다
- **돌려보지 않고 성공을 암시하는 어떤 표현이든**

## 빠져나갈 구멍

| 하고 싶은 말 | 실제 |
|---|---|
| 「이제 될 겁니다」 | 돌려서 확인해라 |
| 「확신합니다」 | 확신은 근거가 아니다 |
| 「이번만 그냥」 | 예외 없음 |
| 「린터가 통과했다」 | 린터는 컴파일러가 아니다 |
| 「빌드가 됐으니 배포도 됐다」 | 상주 프로세스는 재기동해야 바뀐다 |
| 「파일을 덮었으니 반영됐다」 | 서비스를 멈췄다 올렸나 |
| 「도구가 됐다고 했다」 | 형상관리 diff 로 직접 봐라 |
| 「지쳤다」 | 피곤함은 사유가 아니다 |
| 「일부만 봐도 충분하다」 | 일부는 아무것도 증명하지 않는다 |
| 「말을 다르게 했으니 규칙 밖이다」 | 글자가 아니라 취지를 본다 |

## 확인이 막혔을 때

우리 환경에서는 자주 일어난다 — `dotnet build` 가 승인 대기로 막히거나,
TFS 체크아웃이 안 돼 파일이 읽기 전용이거나.

**그때 「됐을 것이다」로 넘어가지 않는다.** 이렇게 적는다.

```
확인 못 함 — dotnet build 가 승인 대기로 거부됨
정적 근거: Npgsql 참조 있음 · ConnectionStringName 은 protected 필드라 접근 가능
사용자가 직접 돌릴 명령: dotnet build SampleApp\SampleApp.csproj
```

**못 한 것을 못 했다고 적는 것도 검증이다.** 빈칸으로 두는 것만 안 된다.

## 사용 시점

**항상, 아래 직전에.**

- 완료·성공을 뜻하는 어떤 표현이든
- 커밋 · 체크인 · PR 생성
- 단계 승인 요청
- 다음 단계로 넘어가기

규칙은 **정확한 문구뿐 아니라 바꿔 말한 것과 성공을 암시하는 모든 표현**에 걸린다.

## 마지막

명령을 돌린다. 출력을 읽는다. **그다음에** 결과를 말한다.
