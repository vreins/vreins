# 자격증명을 문서에 쓰지 않는다

> 상태: 작성완료
> 준수 강도: 필수
> 최종갱신: 2026-09-22

산출물 · 시스템 정의 · 지침 어디에도 **접속 계정과 비밀번호를 적지 않는다.**
위키는 커밋된다. 시스템 정의는 2026-09-22 부터 플러그인에 들어가지 않지만
**그렇다고 안전해진 것이 아니다** — 사람이 주고받고, 별도 저장소로 갈 수 있다.
「어디에 올라가느냐」와 무관하게 적지 않는 것이 규칙이다.

## 적지 않는 것

    DB 계정 · 비밀번호 · 계정이 박힌 커넥션 문자열
    API 키 · 토큰 · 인증서
    서버 관리자 계정
    고객사 개인정보가 든 실 데이터
    실 조업 데이터 원본

## 실제 위치

자리가 정해져 있다. **사람이 적는 곳은 `config\` 하나뿐이다.**

    systems\{유형}\{코드}.json    "postgresql://호스트:포트/DB명"   계정 없는 URL → 커밋된다
    config\{유형}\{코드}.json     계정 · 비밀번호                   → 커밋 경로에 없다
    MCP 설정                      "${VREINS_DB_URL}" 참조만          → 런처가 만든다

**둘을 합치는 자리는 런처 한 곳뿐이다.** 그래서 저장소 어디에도 비밀번호가 없다.
이 구조를 우회해 값을 직접 적으면 그 보장이 그 자리에서 깨진다.

## 데이터가 필요할 때

    테이블 구조(DDL) · 컬럼명 · 인덱스      공유해도 된다
    실 데이터                              마스킹한 샘플 몇 건까지

건수나 분포가 필요하면 **값이 아니라 통계**를 적는다 — 「370건」은 되고
그 370건의 LOT 번호는 안 된다.

## 이미 적혀 있는 것을 발견하면

지우고 넘어가지 않는다. **사용자에게 알린다.** 이미 커밋됐다면 파일에서
지우는 것만으로는 이력에 남아 있고, 그건 사람이 판단할 일이다.
