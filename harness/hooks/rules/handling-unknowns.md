# 모르는 것을 추측하지 않는다

> 상태: 작성완료
> 준수 강도: 필수
> 최종갱신: 2026-09-21

조직 내부 정보는 **일반 지식이 아니다.** 프레임워크 내부 API · 공정 용어 ·
테이블 의미 · 업무 규칙은 지침이나 위키에 적혀 있지 않으면 알 수 없다.

모르면 **모른다고 밝히고 멈춘다.**

    이건 지침에도 위키에도 없다. 실제 코드나 담당자 확인이 필요하다.

## 특히 위험한 것

    프레임워크 API 의 동작      이름이 그럴듯해도 우리 것은 다르게 동작할 수 있다
    공정 용어                   현장 용어는 사전에 없다
    테이블 · 컬럼의 의미         COMMENT 가 정본이다. 이름으로 추정하지 않는다
    업무 규칙                   말로 표현된 적 없는 규칙이 가장 많다

## 빈칸이 나은 이유

비어 있으면 「모른다」가 그대로 보인다. 추측을 채우면 **「있는데 틀린 것」**이 되고,
다음 사람은 확인된 값으로 읽는다. 틀린 줄 아는 사람이 없어진다.

시스템 정의가 경로를 비워 두는 것도 같은 이유다 — 경로가 비면 그 시스템은 메뉴에
안 뜨므로, **모른다는 사실이 그대로 동작에 나타난다.**

## 용어

용어집(`wiki\glossary.md`)에 없는 용어를 임의로 해석하지 않는다.
확인된 용어는 단계 승인 직전에 용어집 추가를 제안한다.
